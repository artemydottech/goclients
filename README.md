# goclients

Проект для обучения. Готовая инфраструктура для **selfhosted** разворачивания аналога сервиса [`yclients`](https://www.yclients.com/) с использованием **Go, SQLite**.

## Быстрый старт

Для компиляции `go-sqlite3` требуется установка `GCC` сервиса.

```bash
git clone https://github.com/artemydottech/goclients.git
cd goclients
cp .env.example .env
go mod tidy
go run .
```

Таблицы создаются на старте, миграции не нужны.

```bash
go test ./...   # тесты валидации
go vet ./...
```

## Переменные окружения

| Переменная | По умолчанию | Назначение              |
| ---------- | ------------ | ----------------------- |
| `DB_PATH`  | `./data.db`  | файл базы SQLite        |
| `PORT`     | `8080`       | порт HTTP-сервера       |

## API

Три ресурса с одинаковым набором операций.

| Метод    | Путь               | Ответ                        |
| -------- | ------------------ | ---------------------------- |
| `POST`   | `/users`           | `201` + `{"id": <int64>}`    |
| `GET`    | `/users`           | `200` + массив пользователей |
| `GET`    | `/users/{id}`      | `200` + пользователь         |
| `DELETE` | `/users/{id}`      | `204`                        |
| `POST`   | `/companies`       | `201` + `{"id": <int64>}`    |
| `GET`    | `/companies`       | `200` + массив компаний      |
| `GET`    | `/companies/{id}`  | `200` + компания             |
| `DELETE` | `/companies/{id}`  | `204`                        |
| `POST`   | `/employees`       | `201` + `{"id": <int64>}`    |
| `GET`    | `/employees`       | `200` + массив сотрудников   |
| `GET`    | `/employees/{id}`  | `200` + сотрудник            |
| `DELETE` | `/employees/{id}`  | `204`                        |

### Коды ошибок

| Код   | Когда                                                          |
| ----- | -------------------------------------------------------------- |
| `400` | тело не разбирается или не прошло валидацию                      |
| `404` | записи с таким `id` нет                                          |
| `405` | метод не совпал с маршрутом                                      |
| `500` | сбой хранилища                                                   |

Сотрудник привязан к компании через `company_id` и удаляется вместе с ней.

### Соц. сети компании

Поле `socials` — объект, где ключом может быть только `vk`, `telegram`,
`whatsapp` или `viber`. Любой другой ключ отклоняется с `400`.

```json
{
  "name": "Ромашка",
  "socials": { "vk": "vk.com/romashka", "telegram": "@romashka" }
}
```
